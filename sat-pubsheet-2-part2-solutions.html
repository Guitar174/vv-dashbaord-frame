Q99Building an exponential modelPDF page 2
There were no jackrabbits in Australia before 1788 when 24 jackrabbits were introduced. By 1920 the population of jackrabbits had reached 10 billion. If the population had grown exponentially, this would correspond to a 16.2% increase, on average, in the population each year. Which of the following functions best models the population p(t) of jackrabbits t years after 1788?
A) p(t) = 1.162(24)t   B) p(t) = 24(2)1.162t   C) p(t) = 24(1.162)t   D) p(t) = (24 · 1.162)t
What is it asking?
Write the equation that starts at 24 rabbits and grows 16.2% every year.
What you need to know
Exponential model: y = (start) × (factor)x. Growth by r% → factor 1 + r. Decay by r% → factor 1 − r (write r as a decimal). The start value is the number in front.
Step-by-step solution
  1. Starting amount (t = 0, the year 1788): 24 rabbits. This number goes in front.
  2. "16.2% increase each year" means each year is 100% + 16.2% = 116.2% of the year before.
  3. 116.2% as a decimal is 1.162. That is the growth factor.
  4. After t years you multiply by 1.162 a total of t times: p(t) = 24(1.162)t.
  5. The 10 billion in 1920 is just background; it isn't needed to pick the form.
Answer: C) p(t) = 24(1.162)t
✅ Check: At t = 0: 24 × 1.1620 = 24 × 1 = 24 rabbits ✓
⚠️ Common mistakes: A swaps the start and the factor. B uses base 2 (that is doubling, not 16.2%). D puts the 24 inside the power, so t = 0 would give 1 rabbit.
Q106Growth that happens every 2 daysPDF page 5
On April 1, there were 233 views of an advertisement posted on a website. Every 2 days after April 1, the number of views of the advertisement had increased by 70% of the number of views 2 days earlier. The function f gives the predicted number of views x days after April 1. Which equation defines f?
A) f(x) = 233(0.70)x/2   B) f(x) = 233(0.70)2x   C) f(x) = 233(1.70)x/2   D) f(x) = 233(1.70)2x
What is it asking?
Build the model: start at 233 and grow by 70% once every 2 days.
What you need to know
Exponential model: y = (start) × (factor)x. Growth by r% → factor 1 + r. Decay by r% → factor 1 − r (write r as a decimal). The start value is the number in front. If the growth happens once every k days, the exponent is x/k (the number of k-day periods that have passed).
Step-by-step solution
  1. Start (x = 0, April 1): 233 → goes in front.
  2. Increase of 70% → multiply by 1 + 0.70 = 1.70. This removes A and B (0.70 would be a 70% drop).
  3. How many times do we multiply? Once every 2 days. After x days, that is x ÷ 2 times.
  4. So the exponent is x/2: f(x) = 233(1.70)x/2.
Answer: C) f(x) = 233(1.70)x/2
✅ Check: After 2 days: 233 × 1.701 = 396.1, which is 70% more than 233 ✓. With D, after 2 days you would get 233 × 1.704 — far too big.
⚠️ Common mistakes: D uses 2x, which means growing twice EVERY day instead of once every 2 days.
Q112What the model predictsPDF page 7
N(d) = 115(0.90)d. The function N defined above can be used to model the number of species of brachiopods at various ocean depths d, where d is in hundreds of meters. Which of the following does the model predict?
A) For every increase in depth by 1 meter, the number of brachiopod species decreases by 115.
B) For every increase in depth by 1 meter, the number of brachiopod species decreases by 10%.
C) For every increase in depth by 100 meters, the number of brachiopod species decreases by 115.
D) For every increase in depth by 100 meters, the number of brachiopod species decreases by 10%.
What is it asking?
Explain in words what happens to the number of species as the depth grows.
What you need to know
Factor 0.90 = keep 90% = lose 10% each time the exponent grows by 1. Watch the units: d = 1 means 100 meters here.
Step-by-step solution
  1. The factor is 0.90. Keeping 90% means a 10% decrease each step. This removes A and C (115 is the starting number, not the change).
  2. Each step is "d increases by 1".
  3. d is measured in hundreds of meters, so d increasing by 1 means the depth increases by 100 meters.
  4. So: every 100 meters deeper, the number of species drops by 10%.
Answer: D) For every increase in depth by 100 meters, the number of species decreases by 10%
⚠️ Common mistakes: B has the right 10% but the wrong unit (1 meter). The question tells you d is in hundreds of meters.
Q115Starting valuePDF page 8

Q118Finding the rate constantPDF page 10
A scientist initially measures 12,000 bacteria in a growth medium. 4 hours later, the scientist measures 24,000 bacteria. Assuming exponential growth, the formula P = C(2)rt gives the number of bacteria in the growth medium, where r and C are constants and P is the number of bacteria t hours after the initial measurement. What is the value of r?
A) 1/12,000   B) 1/4   C) 4   D) 12,000
What is it asking?
Use the two measurements to find C, then r.
What you need to know
At t = 0 the formula gives P = C (because 20 = 1). If 2something = 2, the something must equal 1.
Step-by-step solution
  1. Initial measurement: t = 0, P = 12,000. So 12,000 = C × 20 = C. C = 12,000.
  2. After 4 hours: t = 4, P = 24,000. So 24,000 = 12,000 × 24r.
  3. Divide both sides by 12,000: 2 = 24r.
  4. 2 is the same as 21, so the exponents must match: 4r = 1.
  5. Divide by 4: r = 1/4.
Answer: B) 1/4
✅ Check: With r = 1/4, after 4 hours the exponent is 4 × 1/4 = 1, so the bacteria double: 12,000 → 24,000 ✓
⚠️ Common mistakes: D (12,000) is C, not r. C (4) is the doubling time in hours, not r.
Q120Equivalent exponential formsPDF page 11
For the exponential function f, the value of f(0) is c, where c is a constant. Of the following equations that define the function f, which equation shows the value of c as the coefficient or the base?
A) f(x) = 22(1.5)x+1   B) f(x) = 33(1.5)x   C) f(x) = 49.5(1.5)x−1   D) f(x) = 74.25(1.5)x−2
What is it asking?
All four equations are the same function written differently. Find f(0), then pick the form where that number is written out in front.
What you need to know
In f(x) = a(b)x the number a is the value when x = 0, because b0 = 1. So a is always the starting (initial) amount. Only the plain form a(b)x shows f(0) directly as the coefficient.
Step-by-step solution
  1. Find f(0) using any choice. Choice A: 22 × 1.50+1 = 22 × 1.5 = 33.
  2. Check choice C gives the same: 49.5 × 1.5−1 = 49.5 ÷ 1.5 = 33 ✓. Choice D: 74.25 ÷ 1.5² = 74.25 ÷ 2.25 = 33 ✓.
  3. So c = f(0) = 33.
  4. Which equation shows 33 as the coefficient (the number in front)? Choice B: 33(1.5)x.
Answer: B) f(x) = 33(1.5)x
💡 Tip: When the exponent is exactly x (no +1, −1, −2), the front number is the value at x = 0.
Q121Solving an exponential equationPDF page 12
The function g is defined by g(x) = 105x−8. What is the value of x when g(x) is equal to 10,000?
A) 11/5   B) 12/5   C) 3   D) 4
What is it asking?
Solve 105x−8 = 10,000.
What you need to know
Write both sides as a power of the same base. If 10a = 10b, then a = b.
Step-by-step solution
  1. 10,000 = 10 × 10 × 10 × 10 = 104.
  2. So 105x−8 = 104.
  3. Same base 10 → set the exponents equal: 5x − 8 = 4.
  4. Add 8: 5x = 12.
  5. Divide by 5: x = 12/5.
Answer: B) 12/5
✅ Check: 5(12/5) − 8 = 12 − 8 = 4, and 104 = 10,000 ✓
⚠️ Common mistakes: D (4) is the exponent, not x. A comes from 5x − 8 = 3.

Q135Counting doublingsPDF page 17
Bacteria are growing in a liquid growth medium. There were 300,000 cells per milliliter during an initial observation. The number of cells per milliliter doubles every 3 hours. How many cells per milliliter will there be 15 hours after the initial observation?
A) 1,500,000   B) 2,400,000   C) 4,500,000   D) 9,600,000
What is it asking?
Find how many times the amount doubles in 15 hours, then multiply.
What you need to know
Number of doublings = total time ÷ doubling time. Doubling n times multiplies by 2n.
Step-by-step solution
  1. Doublings: 15 hours ÷ 3 hours = 5 doublings.
  2. 25 = 2 × 2 × 2 × 2 × 2 = 32.
  3. 300,000 × 32 = 9,600,000.
Answer: D) 9,600,000
✅ Check: 300k → 600k (3 h) → 1.2M (6 h) → 2.4M (9 h) → 4.8M (12 h) → 9.6M (15 h) ✓
⚠️ Common mistakes: A (1.5M) is 300,000 × 5 — multiplying by the number of doublings instead of doubling 5 times. B (2.4M) is only 3 doublings.

h(t) = −16t² + 110t + 72. The function above models the height h, in feet, of an object above ground t seconds after being launched straight up in the air. What does the number 72 represent in the function?

C) The initial speed, in feet per second, of the object   D) The maximum speed, in feet per second, of the object
What is it asking?
Explain what 72 means.
What you need to know
In h(t) = at² + bt + c, the constant c is the value at t = 0 — the starting height.
Step-by-step solution
  1. "Launched" means t = 0 seconds.
  2. h(0) = −16(0)² + 110(0) + 72 = 72.
  3. So 72 feet is the height at the start (the initial height).
Answer: A) The initial height, in feet, of the object

Q103Vertex formPDF page 3
f(θ) = −0.28(θ − 27)² + 880. An engineer wanted to identify the best angle for a cooling fan in an engine in order to get the greatest airflow. The engineer discovered that the function above models the airflow f(θ), in cubic feet per minute, as a function of the angle of the fan θ, in degrees. According to the model, what angle, in degrees, gives the greatest airflow?
A) −0.28   B) 0.28   C) 27   D) 880
What is it asking?
Find the angle where the airflow is largest.
What you need to know
Vertex form: f(x) = a(x − h)² + k. The vertex is (h, k). If a is negative, the parabola opens down and the vertex is the MAXIMUM point.
Step-by-step solution
  1. Match f(θ) = −0.28(θ − 27)² + 880 with a(x − h)² + k.
  2. a = −0.28 (negative → opens down → the vertex is the highest point).
  3. h = 27, k = 880. So the vertex is (27, 880).
  4. The greatest airflow (880) happens at angle θ = 27°.
Answer: C) 27
✅ Check: At θ = 27, the squared part is (0)² = 0, so f = 880. Any other angle makes the squared part positive, and multiplying by −0.28 subtracts from 880.
⚠️ Common mistakes: D (880) is the greatest AIRFLOW, but the question asks for the ANGLE.

Q125Evaluating a polynomialPDF page 13
