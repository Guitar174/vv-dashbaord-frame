Q150Rearranging a formulaPDF page 2
During a 5-second time interval, the average acceleration a, in meters per second squared, of an object with an initial velocity of 12 meters per second is defined by the equation a = (vf − 12)/5, where vf is the final velocity in meters per second. If the equation is rewritten in the form vf = xa + y, where x and y are constants, what is the value of x?
What is it asking?
The formula currently gives a by itself. They want the SAME formula rearranged so that vf is by itself. Then they want the number that multiplies a.
What you need to know
To isolate a variable, undo the operations done to it in reverse order. Whatever you do to one side, you must do to the other side.
Step-by-step solution
  1. Look at what happens to vf in the formula a = (vf − 12)/5. First 12 is subtracted, THEN the result is divided by 5.
  2. Undo the LAST operation first. The last operation was "divide by 5", so multiply both sides by 5:
    5 × a = 5 × (vf − 12)/5
    5a = vf − 12
  3. Now undo "subtract 12" by adding 12 to both sides:
    5a + 12 = vf − 12 + 12
    5a + 12 = vf
  4. Flip the sides so it reads the same way as the question: vf = 5a + 12.
  5. Compare with vf = xa + y. The number in front of a is 5, so x = 5 (and y = 12).
Answer: x = 5
✅ Check: Pick a = 2. Then vf = 5(2) + 12 = 22. Put back into the original: (22 − 12)/5 = 10/5 = 2 ✓
💡 Tip: Reverse order: the operation done LAST is undone FIRST — like taking off shoes before socks.
Q14Where two graphs intersectPDF page 3
In the xy-plane, the graph of y = 3x² − 14x intersects the graph of y = x at the points (0, 0) and (a, a). What is the value of a?
What is it asking?
Two graphs cross at some points. One crossing is (0, 0). We need the x-value (also the y-value) of the OTHER crossing.
What you need to know
At an intersection point, both equations give the same y for the same x. So you set the right-hand sides equal to each other.
Step-by-step solution
  1. Both equations start with "y =". At a crossing point the y-values match, so:
    3x² − 14x = x
  2. This is a quadratic (it has x²). Get everything on one side so the other side is 0. Subtract x from both sides:
    3x² − 14x − x = 0
    3x² − 15x = 0
  3. Both terms contain 3x, so factor it out:
    3x(x − 5) = 0
  4. A product equals zero only if one of the factors is zero:
    3x = 0 → x = 0,  or  x − 5 = 0 → x = 5
  5. x = 0 gives the point (0, 0) that the question already told us. The OTHER point uses x = 5.
  6. Because the point is on y = x, its y-value equals its x-value: (5, 5). So a = 5.
Answer: a = 5
✅ Check: Put x = 5 into y = 3x² − 14x: 3(25) − 70 = 75 − 70 = 5. So (5, 5) is on both graphs ✓
⚠️ Common mistakes: Do NOT divide both sides by x to "cancel" it — you would lose the solution x = 0. Always move everything to one side and factor.
💡 Tip: "Intersect", "meet", "cross" → set the two equations equal to each other.

Q25Reading a linear equationPDF page 5
5G + 45R = 380. At a school fair, students can win colored tokens that are worth a different number of points depending on the color. One student won G green tokens and R red tokens worth a total of 380 points. The given equation represents this situation. How many more points is a red token worth than a green token?
What is it asking?
We must figure out how many points ONE green token is worth and how many ONE red token is worth, then subtract.
What you need to know
In an equation like (price)(amount) + (price)(amount) = total, the number in front of each variable is the value of ONE item.
Step-by-step solution
  1. G is the NUMBER of green tokens. If each green token is worth p points, the green tokens give p × G points in total.
  2. In the equation, the green part is 5G. So each green token is worth 5 points.
  3. The red part is 45R. So each red token is worth 45 points.
  4. The total 380 is just the student's total score — it is not needed for this question.
  5. "How many more" means subtract: 45 − 5 = 40.
Answer: 40
✅ Check: If the student had 1 green and 1 red token: 5 + 45 = 50 points, and the red one gave 40 more than the green one ✓
💡 Tip: Coefficient = value per item. Variable = how many items.
Q28Finding a line from a tablePDF page 6
The table gives the coordinates of two points on a line in the xy-plane: (k, 13) and (k + 7, −15). The y-intercept of the line is (k − 5, b), where k and b are constants. What is the value of b?
What is it asking?
We have a line through two points that contain an unknown k. We need b, the y-value where the line crosses the y-axis.
What you need to know
Every y-intercept has x-coordinate 0 (it sits on the y-axis). Slope = (change in y) ÷ (change in x).
Step-by-step solution
  1. The y-intercept is written as (k − 5, b). Any point on the y-axis has x = 0, so:
    k − 5 = 0 → k = 5.
  2. Replace k with 5 in the table. The two points become (5, 13) and (5 + 7, −15) = (12, −15).
  3. Find the slope:
    m = (−15 − 13) ÷ (12 − 5) = −28 ÷ 7 = −4.
    This means every time x goes UP by 1, y goes DOWN by 4.
  4. Now go from the point (5, 13) back to x = 0. That is 5 steps to the LEFT.
  5. Going left is the opposite of going right, so instead of y going down 4 each step, y goes UP 4 each step: 5 × 4 = 20.
  6. So the y-value at x = 0 is 13 + 20 = 33. Therefore b = 33.
  7. (Algebra version: y − 13 = −4(x − 5) → y = −4x + 20 + 13 = −4x + 33. The constant 33 is the y-intercept.)
Answer: b = 33
✅ Check: Line y = −4x + 33. At x = 5: −20 + 33 = 13 ✓. At x = 12: −48 + 33 = −15 ✓
💡 Tip: Whenever a y-intercept is written with a variable x-coordinate, set that x-coordinate equal to 0.
Q37Finding a line from a tablePDF page 7
The table shows two values of x and their corresponding values of y: (−18, −48) and (7, 52). In the xy-plane, the graph of the linear equation representing this relationship passes through the point (1/7, a). What is the value of a?
What is it asking?
Find the equation of the line through the two points, then plug in x = 1/7 to get the y-value a.
What you need to know
Slope m = (y₂ − y₁)/(x₂ − x₁). Point-slope form: y − y₁ = m(x − x₁).
Step-by-step solution
  1. Slope: m = (52 − (−48)) ÷ (7 − (−18)) = (52 + 48) ÷ (7 + 18) = 100 ÷ 25 = 4.
  2. Use point (7, 52) in point-slope form: y − 52 = 4(x − 7).
  3. Distribute: y − 52 = 4x − 28.
  4. Add 52 to both sides: y = 4x + 24.
  5. Now plug in x = 1/7: a = 4 × (1/7) + 24 = 4/7 + 24.
  6. Write 24 as a fraction with denominator 7: 24 = 168/7.
  7. Add: a = 4/7 + 168/7 = 172/7.
Answer: D) 172/7
✅ Check: Check the other table point in y = 4x + 24: 4(−18) + 24 = −72 + 24 = −48 ✓
⚠️ Common mistakes: A and B are negative — but the line has positive slope and y-intercept 24, so at x = 1/7 the value must be a bit more than 24. C (4/7) forgot to add the +24.
Q77Translating a linePDF page 8
For line h, the table shows three values of x and their corresponding values of y: (18, 130), (23, 160), (26, 178). Line k is the result of translating line h down 5 units in the xy-plane. What is the x-intercept of line k?
What is it asking?
Find the equation of line h, shift it down 5 to get line k, then find where k crosses the x-axis (where y = 0).
What you need to know
Translating a graph DOWN by 5 means subtracting 5 from every y-value: y = mx + b becomes y = mx + (b − 5). The slope does not change.
Step-by-step solution
  1. Slope of h using the first two points: (160 − 130) ÷ (23 − 18) = 30 ÷ 5 = 6.
  2. Double-check with the third point: (178 − 160) ÷ (26 − 23) = 18 ÷ 3 = 6 ✓ (so it really is a line).
  3. Equation of h: y − 130 = 6(x − 18) → y = 6x − 108 + 130 → y = 6x + 22.
  4. Move the line down 5 units: subtract 5 from the constant. Line k: y = 6x + 17.
  5. x-intercept means y = 0: 0 = 6x + 17.
  6. Subtract 17: −17 = 6x. Divide by 6: x = −17/6.
  7. Write it as a point: (−17/6, 0).
Answer: D) (−17/6, 0)
✅ Check: 6 × (−17/6) + 17 = −17 + 17 = 0 ✓
⚠️ Common mistakes: C (−11/3, 0) is the x-intercept of the ORIGINAL line h (6x + 22 = 0 → x = −11/3). That's the trap if you forget to shift down.
Q84Mixture problemPDF page 9
How many liters of a 25% saline solution must be added to 3 liters of a 10% saline solution to obtain a 15% saline solution?
What is it asking?
We mix a stronger solution (25%) with a weaker one (10%) to get something in between (15%). We need how much of the strong one to add.
What you need to know
Amount of salt = (percent as a decimal) × (liters). The salt from each part adds up to the salt in the final mix.
Step-by-step solution
  1. Let x = liters of the 25% solution we add.
  2. Salt from the 25% solution: 0.25 × x = 0.25x liters of salt.
  3. Salt from the 10% solution: 0.10 × 3 = 0.3 liters of salt.
  4. Total volume after mixing: x + 3 liters. At 15%, it contains 0.15(x + 3) liters of salt.
  5. Salt in = salt out:
    0.25x + 0.3 = 0.15(x + 3)
  6. Distribute on the right: 0.25x + 0.3 = 0.15x + 0.45.
  7. Subtract 0.15x from both sides: 0.10x + 0.3 = 0.45.
  8. Subtract 0.3: 0.10x = 0.15.
  9. Divide by 0.10: x = 1.5.
Answer: 1.5 liters
✅ Check: Salt: 0.25(1.5) + 0.3 = 0.375 + 0.3 = 0.675. Volume: 4.5 L. 0.675 ÷ 4.5 = 0.15 = 15% ✓
💡 Tip: Multiply both sides by 100 first to avoid decimals: 25x + 30 = 15x + 45 → 10x = 15.
Q116Perpendicular slopePDF page 10
Line p is defined by 4y + 8x = 6. Line r is perpendicular to line p in the xy-plane. What is the slope of line r?
What is it asking?
Find the slope of line p, then use the perpendicular rule to get the slope of r.
What you need to know
Slope is easiest to read in the form y = mx + b. Perpendicular lines have slopes that are negative reciprocals (flip the fraction AND change the sign). Their product is −1.
Step-by-step solution
  1. Start with 4y + 8x = 6. We want y alone.
  2. Subtract 8x from both sides: 4y = −8x + 6.
  3. Divide every term by 4: y = −2x + 1.5.
  4. The slope of p is the coefficient of x: m = −2.
  5. Negative reciprocal of −2: write −2 as −2/1, flip it → −1/2, change the sign → +1/2.
  6. So the slope of r is 1/2.
Answer: 1/2 (or 0.5)
✅ Check: (−2) × (1/2) = −1 ✓ — that's the perpendicular test.
⚠️ Common mistakes: Common mistake: using 8 as the slope (forgetting to divide by 4) or only changing the sign (answer 2) or only flipping (answer −1/2).
Q17Writing an inequalityPDF page 11
A team hosting an event to raise money for new uniforms plans to sell at least 140 tickets before this event and at least 220 tickets during this event to raise a total of at least $5,820 from all tickets sold. The price of a ticket during this event is $3 less than the price of a ticket before this event. Which inequality represents this situation, where x is the price, in dollars, of a ticket sold during this event?
What is it asking?
Build an expression for the total money raised, then compare it to $5,820 using the right inequality sign.
What you need to know
Money = price × number sold. "At least" means ≥ (that amount or more).
Step-by-step solution
  1. x = price of a ticket DURING the event (given).
  2. The during-price is $3 LESS than the before-price. So the before-price is $3 MORE than x: x + 3.
  3. Money from tickets before the event: 140 × (x + 3).
  4. Money from tickets during the event: 220 × x.
  5. Total money: 140(x + 3) + 220x.
  6. The team wants to raise "at least $5,820" → total ≥ 5,820.
  7. Inequality: 140(x + 3) + 220x ≥ 5,820.
Answer: B) 140(x + 3) + 220x ≥ 5,820
⚠️ Common mistakes: C and D use (x − 3): that would make the before-price cheaper, which is backwards. A uses ≤, which would mean "at most".
Q58Checking points in an inequalityPDF page 12
y < 6x + 2. For which of the following tables are all the values of x and their corresponding values of y solutions to the given inequality?
What is it asking?
Each choice is a table of (x, y) points. We need the table where EVERY point makes y < 6x + 2 true.
What you need to know
To test a point, plug in x, compute 6x + 2, and see whether y is strictly SMALLER. With "<" (not "≤"), a point where y equals 6x + 2 does NOT count.
Step-by-step solution
  1. Test choice A, row 1: x = 3, y = 20. Compute 6(3) + 2 = 18 + 2 = 20.
  2. Is 20 < 20? No — 20 is equal, not less. So this row fails.
  3. One failing row is enough to reject the whole table, so A is wrong.
  4. (Rows 2 and 3 of A also sit exactly on the line: 6(5) + 2 = 32 and 6(7) + 2 = 44 — all equal, none less.)
  5. For choices B, C, D do the same test on every row. The correct table is the one where every y is below 6x + 2.
Answer: Not A (see note)
💡 Tip: Strict inequality (< or >): points ON the boundary line are NOT solutions.

Q72Budget inequality (maximum)PDF page 13
A small business owner budgets $2,200 to purchase candles. The owner must purchase a minimum of 200 candles to maintain the discounted pricing. If the owner pays $4.90 per candle to purchase small candles and $11.60 per candle to purchase large candles, what is the maximum number of large candles the owner can purchase to stay within the budget and maintain the discounted pricing?
What is it asking?
We want as many large candles as possible, while (1) total cost ≤ $2,200 and (2) total candles ≥ 200.
What you need to know
Large candles are expensive, so to fit the most of them, spend as little as possible on small candles — buy only enough small candles to reach exactly 200 total.
Step-by-step solution
  1. Let L = number of large candles, S = number of small candles.
  2. Rules: S + L ≥ 200 (minimum candles) and 4.90S + 11.60L ≤ 2,200 (budget).
  3. Extra candles cost money without helping, so use exactly 200 total: S = 200 − L.
  4. Substitute into the budget: 4.90(200 − L) + 11.60L ≤ 2,200.
  5. Multiply out: 980 − 4.90L + 11.60L ≤ 2,200 → 980 + 6.70L ≤ 2,200.
  6. Subtract 980: 6.70L ≤ 1,220.
  7. Divide by 6.70: L ≤ 182.09…
  8. Candles must be whole numbers, and we cannot go OVER the budget, so round DOWN: L = 182.
Answer: 182
✅ Check: 182 large + 18 small = 200 candles. Cost: 182(11.60) + 18(4.90) = 2,111.20 + 88.20 = $2,199.40 ≤ $2,200 ✓. With 183 large + 17 small: 2,122.80 + 83.30 = $2,206.10 — over budget ✗
💡 Tip: "Maximum" in a budget problem → always round DOWN, even if the decimal is .9.

Q95Angles with parallel linesPDF page 15
A line intersects two parallel lines, forming four acute angles and four obtuse angles. The measure of one of the acute angles is (9x − 560)°. The sum of the measures of one of the acute angles and three of the obtuse angles is (−18x + w)°. What is the value of w?
What is it asking?
Write the sum "one acute + three obtuse" in terms of x, then match it to −18x + w to find w.
What you need to know
When a line crosses parallel lines, all 4 acute angles are equal and all 4 obtuse angles are equal. An acute angle and an obtuse angle next to each other form a straight line, so they add to 180°.
Step-by-step solution
  1. Acute angle = (9x − 560)°. All acute angles have this size.
  2. Obtuse angle = 180 − (acute) = 180 − (9x − 560).
  3. Careful with the minus sign: 180 − 9x + 560 = 740 − 9x.
  4. Sum of one acute and three obtuse:
    (9x − 560) + 3(740 − 9x)
  5. Distribute the 3: 9x − 560 + 2,220 − 27x.
  6. Combine x-terms: 9x − 27x = −18x. Combine numbers: −560 + 2,220 = 1,660.
  7. Sum = −18x + 1,660. Compare with −18x + w → w = 1,660.
Answer: w = 1,660
✅ Check: The −18x part matches the question exactly, which confirms the setup is right.
💡 Tip: Parallel lines + transversal → only two angle sizes, and they are supplementary (add to 180°).
Q101Parallel lines — which sum is impossiblePDF page 16
A line intersects two parallel lines, forming four acute angles and four obtuse angles. The measure of one of these eight angles is (7x − 250)°. The sum of the measures of four of the eight angles is k°. Which of the following could NOT be equivalent to k, for all values of x?
What is it asking?
List every possible sum of four angles, then find the answer choice that is NOT on the list.
What you need to know
Only two sizes exist: call one a, then the other is 180 − a. Choosing 4 angles means choosing how many are size a (0 to 4).
Step-by-step solution
  1. Let a = 7x − 250. The other angle size is 180 − a = 180 − 7x + 250 = 430 − 7x.
  2. Case 4 of size a: 4a = 4(7x − 250) = 28x − 1,000.
  3. Case 3a + 1(180 − a): = 2a + 180 = 14x − 500 + 180 = 14x − 320. ← choice B
  4. Case 2a + 2(180 − a): = 360 (the a's cancel). ← choice D
  5. Case 1a + 3(180 − a): = 540 − 2a = 540 − 14x + 500 = −14x + 1,040.
  6. Case 4(180 − a): = 720 − 4a = 720 − 28x + 1,000 = −28x + 1,720. ← choice C
  7. Choice A is −14x + 1,540. The only sum with −14x is −14x + 1,040, not 1,540. So A is impossible.
Answer: A) −14x + 1,540
💡 Tip: Organize by cases (0, 1, 2, 3, 4 of one type) so you never miss a possibility.
Q53Tangent lines to a circlePDF page 17
A circle has center O, and points A and U lie on the circle. Line segments AE and UE are tangent to the circle at points A and U, respectively. The distance between point O and point E is 510 centimeters and the distance between point O and point U is 78 centimeters. What is the area, in square centimeters, of quadrilateral OAEU?
What is it asking?
Find the area of the 4-sided shape O–A–E–U formed by two radii and two tangent lines.
What you need to know
A tangent line is always perpendicular to the radius at the touching point (90° angle). Two tangents from the same outside point are equal in length.
Step-by-step solution
  1. Draw it: O is the center, E is outside the circle, and AE and UE touch the circle at A and U.
  2. OU = 78 is a radius, so OA = 78 too.
  3. Because UE is tangent at U, angle OUE = 90°. So triangle OUE is a right triangle with hypotenuse OE = 510 and leg OU = 78.
  4. Pythagorean theorem for the other leg UE:
    UE² = 510² − 78² = 260,100 − 6,084 = 254,016
    UE = √254,016 = 504.
  5. The line OE cuts the quadrilateral into two identical right triangles: OUE and OAE (same radius, same hypotenuse).
  6. Area of one right triangle = ½ × leg × leg = ½ × 78 × 504 = 19,656.
  7. Two triangles: 2 × 19,656 = 39,312.
Answer: 39,312 cm²
✅ Check: 78, 504, 510 is 6 × (13, 84, 85), a known right triangle: 13² + 84² = 169 + 7,056 = 7,225 = 85² ✓
💡 Tip: Tangent ⟂ radius. This turns almost every tangent problem into a right-triangle problem.
Q64Complementary angles in trigPDF page 18
Acute angle P has a measure of p radians, and acute angle T has a measure of t radians. The function g is defined by g(x) = p(8)x + 6t. If sin p = cos t, which of the following represents the value g(0) in terms of t?
What is it asking?
Simplify g(0), then use sin p = cos t to replace p with something in terms of t.
What you need to know
For acute angles, sin p = cos t exactly when p + t = 90° = π/2 radians (complementary angles). Also, any nonzero number to the power 0 equals 1.
Step-by-step solution
  1. Plug x = 0 into g: g(0) = p · 80 + 6t.
  2. 80 = 1, so g(0) = p · 1 + 6t = p + 6t.
  3. sin p = cos t, and both angles are acute, so they are complementary: p + t = π/2.
  4. Solve for p: p = π/2 − t.
  5. Substitute: g(0) = (π/2 − t) + 6t.
  6. Combine the t-terms: −t + 6t = 5t. So g(0) = 5t + π/2.
Answer: D) 5t + π/2
⚠️ Common mistakes: A and B come from treating 80 as 0 or forgetting to replace p. C uses π instead of π/2 (π radians = 180°, not 90°).

What is the perimeter of an equilateral triangle with a height of 39√3?
What is it asking?
Use the height to find the side length, then multiply by 3.
What you need to know
The height of an equilateral triangle splits it into two 30-60-90 triangles. Height = (√3/2) × side. (Short leg = half the side, long leg = height = √3 × short leg.)

Q6Line of best fit — choosing the equationPDF page 22
The scatterplot shows a company's ice cream sales d, in dollars, and the high temperature t, in degrees Celsius (°C), on 12 different days. A line of best fit for the data is also shown. Which of the following could be an equation of the line of best fit?
A) d = 0.03t + 402   B) d = 10t + 402   C) d = 33t + 300   D) d = 33t + 84
What is it asking?
Read the drawn line from the graph and match its slope and position to one equation.
What you need to know
Every line d = mt + b has slope m = (change in d)/(change in t). Be careful: this graph's axes start at t = 10 and d = 300, NOT at 0, so the y-intercept can't be read directly.
Step-by-step solution
  1. Pick two points that sit ON the drawn line (not the dots). The line passes near (12, 480) and (25, 910).
  2. Slope = (910 − 480) ÷ (25 − 12) = 430 ÷ 13 ≈ 33. So sales rise about $33 per 1°C.
  3. A (slope 0.03) and B (slope 10) are far too small → eliminate them.
  4. C and D both have slope 33. Decide by testing a point. Use t = 12, where the line is about 480.
  5. C: 33(12) + 300 = 396 + 300 = 696 — the line is nowhere near 696 at t = 12 ✗
  6. D: 33(12) + 84 = 396 + 84 = 480 ✓
Answer: D) d = 33t + 84
✅ Check: D at t = 25: 33(25) + 84 = 825 + 84 = 909 ≈ 910 ✓
⚠️ Common mistakes: C looks tempting because the bottom of the y-axis is labeled 300 — but that is not where t = 0; t = 0 is off the left edge of the graph.
Q26Line of best fit — choosing the equationPDF page 23
The scatterplot shows the size x (thousands of square feet) and the sale price y (thousands of dollars) of 25 houses for sale in Town H. Which of the following could be an equation for a line of best fit for the data?
A) y = 200x + 100   B) y = 100x + 100   C) y = 50x + 100   D) y = 100x
What is it asking?
